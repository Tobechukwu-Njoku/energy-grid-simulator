## Confirmed findings

1. **High — coverage is not gap-free.** BOALF has five absent periods across four
   dates: 2024-03-14/21, 2024-07-08/27, 2024-09-22/29, 2024-11-03/23 and /24.
   Independent UTC interval-overlap checks find the same absences. Targeted live
   API queries returned HTTP 200 and zero records for all five on this review date.
   This does not establish that no balancing activity occurred. MID lacks one
   APXMIDP and 44 N2EXMIDP observations; full settlement-period union hides those
   provider gaps. Greenlink has 7,102 observations and 10,466 full-year absences in
   each of FUELHH and interconnector flows, including 6,704 absences between its
   first and last observations. Missing records must not be filled with zero.

2. **High — REMIT identifiers were mislabelled as outages.** Measured 48,191 raw
   rows, 15,638 distinct `mrid` values, 15,492 identifiers occurring in
   `UnavailabilitiesOfElectricityFacilities`, and 161 in `OtherMarketInformation`.
   These sets overlap, so they do not sum to the union. There is one exact duplicate,
   leaving 48,190 unique full payloads/message keys. There are 47,427 distinct
   `(mrid, revisionNumber)` pairs; that pair alone would incorrectly collapse real
   publications/asset records. 33,040 rows have revisionNumber greater than one.
   Publication windows cannot guarantee all outages overlapping 2024: messages
   initially published outside 2024 can be absent.

3. **Medium — reference and acceptance counts need qualified labels.** The BM
   reference endpoint is current, not a 2024 historical roster. It contains 3,134
   rows but 3,133 National Grid unit IDs (`WLNYO-4` has two rows), 3,054 non-null
   Elexon IDs (79 null rows), and 424 non-null EICs (2,710 null rows). The original
   retrieval time was not recorded. Do not invent it from filesystem timestamps.
   BOALF's 3,469,685 rows are acceptance profile segments, not that many distinct
   instructions; a separate streaming count finds 1,347,595 distinct
   `(nationalGridBmUnit, acceptanceNumber, acceptanceTime)` keys.

4. **Medium — verification tooling needed correction.** The partial patch loaded
   whole arrays and automatically replaced checksum baselines. Readers now stream
   JSON/gzip through the pinned ijson parser, existing indexes are verified by
   default, and index replacement requires `--refresh-checksums`. Report timestamps
   are preserved for reproducible reruns. Missing input directories fail before
   report writes. Cache validation and worker failure propagation are tested.

5. **Medium — licence attribution was incomplete.** Confirmed the published BMRS
   licence, including commercial use, the exact required Elexon attribution,
   onward sublicensing obligations, no endorsement/misrepresentation, and the
   personal-data/third-party-rights exclusions. Added the licence link and
