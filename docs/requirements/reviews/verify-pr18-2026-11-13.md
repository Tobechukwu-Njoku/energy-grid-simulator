imbalance timestamps lack file-specific timezone confirmation, and the IDC sheet

STATUS.md and the decisions log were not edited, as explicitly instructed.

All Python commands used `-I`. The independent
[`recount.py`](../../../spikes/data-gathering/semo-2024/recount.py) does not import
the downloader or reuse claimed counts. It streams SHA-256 in 1 MiB blocks, copies
the nested XLSX to an external temporary seekable file, streams worksheet XML with
parent removal, and streams the ZIP-contained CSV with `csv.DictReader`. It keeps
only the shared-string lookup, 2024 timestamp keys, IDC field keys, and aggregates.
No pandas, whole-sheet lists, or raw source tables are committed. No application
code was added; the script is part of the D-31 data spike.

Reproduce from the PR checkout:

```sh
python3 -I spikes/data-gathering/semo-2024/recount.py > /tmp/semo-2024-recount.json
python3 -I spikes/data-gathering/semo-2024/fetch.py --verify-only
python3 -I spikes/data-gathering/semo-2024/fetch.py --dry-run
```

The raw root defaults to `/home/njotob/energy-data/raw/semo/2024/`; pass a directory
as the recount's first positional argument to override it. The final recount's
peak resident memory was 60,140 KiB (approximately 58.7 MiB), below the 8 GiB
machine limit. Its JSON output remains outside git.

Auction counts use the half-open UTC year. Independent expected grids use
60-minute DAM, 30-minute IDA1 and imbalance, and five-minute operational pricing.
IDA2/3 grids use 11:00–23:00 / 17:00–23:00 Europe/Dublin civil time and are then
compared as UTC instants. The timezone assumption for the offsetless CSV is
explicit in COVERAGE.md, recount output, and Q-C-11; raw-label duplicate/gap
comparisons do not independently establish that timezone.

membership changes. No synthetic expansion or collapse is appropriate.
