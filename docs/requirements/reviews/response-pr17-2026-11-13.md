## Adversarial findings

| ID | Disposition and resulting contract |
|---|---|
| ADV17-01 | **Accepted default change.** Valkey BSD-3-Clause is recommended; Redis is a compatible assessed alternative, and clients use only shared Redis-protocol features. This remains a proposed refinement of D-3 through Q-I-5, not an invented decision. The existing separate-service AGPL analysis is retained accurately: copyleft does not automatically extend to independent clients. |
| ADV17-02 | **Accepted.** Fixed seeds, thread counts, solver/library/build/platform versions, stable ordering and a consistent boundary warm-start policy are execution provenance. Recovery uses persisted physical state; no portable MIP search-tree restoration is claimed. Bit identity is explicitly not promised for alternative MIP optima, tolerance/time-limit/parallel outcomes. Record gap/tolerances, resume boundary and repeatability limitations; independently enforce physical/numerical acceptance. |
| ADV17-03 | **Accepted.** Stale writes are fenced immediately. Before lease reclaim/successor launch, confirm the prior cgroup/tree is dead or kill/reap it, record evidence and release its reservation. Then atomically reserve against current headroom. An unreachable remote host blocks reclaim until positive fencing. Never admit simultaneous reservations above the RAM budget. |
| ADV17-04 | **Accepted.** Write to a registered staging prefix, commit a pending manifest, promote and verify final objects, then atomically expose available pointers/coverage. Pending intent is not completed output. An N-hour sweeper (proposed N=24) lists staging/multipart uploads for cleanup and rechecks active/pending/retained references under PostgreSQL locking. Partial final copies are discoverable from pre-registered promotion keys. LIST is not a publication mechanism. |
| ADV17-05 | **Accepted failure-policy correction.** A bounded UC↔redispatch loop reports non-convergence and invokes a capability-checked, bounded network-aware joint UC/redispatch fallback for that window. A validated feasible result continues the run; iteration exhaustion alone never fails the whole run. Persist fallback evidence and rerun final-commitment pricing. If fallback also cannot produce valid state, retain honest partial coverage; do not invent state or relax security rows. No arbitrary branch/proxy slack is accepted. Reconcile exact settings with PR #4 round 3 before baseline. |
| ADV17-06 | **Accepted.** PostgreSQL row-locked retained-unpinned/retained-pinned/tombstoned/deleting/deleted transitions govern pin, resume and GC. External deletion starts only after a committed tombstone. Pins/resumes on tombstoned runs are rejected even if files remain. Existing reference/reader holds prevent tombstoning; deletion is idempotent. |
| ADV17-07 | **Accepted clarification.** Versioned transport envelopes and authorised blob references are independent of local handles from the outset. fd passing is a local adapter optimisation. A network adapter uses the same scientific contracts without rewriting engine/solver interfaces. |
| ADV17-08 | **Accepted.** Heavy analytics and sweep reductions are resource-admitted worker jobs outside API/supervisor. API reads have row/byte/time bounds; heartbeat/watchdog execution has reserved CPU/RAM and never performs scans. |
| ADV17-09 | **Accepted labelling policy; blanket impossibility rejected.** Unknown historical publication times yield **reconstruction**, not fabricated as-of evidence or rejection of historical research. Evidence-backed archives and future captured vintages can support as-of runs. Q-O-1 exposes this product claim for disposition. |
| ADV17-10 | **Addressed.** ADR 0002 specifies canonical binary64 values for non-money TOML floats, exact rational schema-unit conversion with one rounding, fixed-width canonical numeric bytes and typed decimal money. FX stays a pinned execution input. Cross-platform golden vectors follow baseline; hash stability is not an assertion of identical solver outputs. |
| ADV17-11 | **Rejected.** PostGIS is a separate PostgreSQL server extension; its GPL does not extend to independent application client code. The owner's baseline includes it, and it remains optional in P1. Packaging/version obligations still apply; coordinates do not replace all spatial indexing/joins. |
| ADV17-12 | **Addressed.** Cooperative native interrupt is capability-dependent; two seconds is a proposed grace, not a guarantee that BLAS/native code responds. The independent watchdog kills/reaps the whole tree under the proposed five-second total target. Failure to prove death blocks reuse; each adapter still needs timing qualification. |
| ADV17-13 | **Addressed.** Immutable blobs/manifests are never rewritten. Version-specific Arrow adapters explicitly project compatible old/new schemas before scans/unions; semantic/unit incompatibility is rejected. Materialised migrations produce new derived releases/hashes. |
| ADV17-14 | **Clarified.** One initial simulation reservation is P1 admission, not a claim that state-dependent time windows can safely run in parallel. P2 adds admitted independent sweep children/nodes and forecast priority; within-run parallel blocks need explicit boundary reconciliation evidence. No timing result or concurrency capacity is invented. |
